# MSc 3 — Clinical Radiology NLP Benchmark

## Purpose

Benchmark privacy-preserving methods for extracting level-resolved, multi-label findings from English lumbar MRI reports at one Middle Eastern teaching hospital.

## Start here

1. Read `RESEARCH_PLAN.md`.
2. Read `DATA_AND_GOVERNANCE.md`.
3. Freeze the annotation manual and locked test set before prompt development.
4. Build the rule-based baseline first.
5. Register each model and prompt version in `EXPERIMENT_REGISTRY.csv`.
