# Data and Governance Checklist

- [ ] Hospital/ethics authority recorded.
- [ ] Reports de-identified or accessed in an approved restricted environment.
- [ ] No clinical text copied into public repositories or external services without approval.
- [ ] Annotation manual completed before annotation.
- [ ] Document-level train/validation/test split locked.
- [ ] Test set independently annotated and adjudicated where feasible.
- [ ] Missingness is distinguished from confirmed negative findings.
- [ ] Model and prompt versions recorded.
- [ ] Outputs checked for unsupported findings and patient identifiers.
