# MSc Research Workspaces

This folder contains four independent starter workspaces based on the approved programme plans.

Each student should treat their folder as a separate research project. The plans are starting points, not frozen conclusions: extensions are welcome if they are documented in the project changelog and approved by the supervisor.

## Shared rules

- Use patient/document-level separation where applicable; never split images or report sections across partitions.
- Do not use local data until the hospital governance and de-identification requirements are satisfied.
- Do not describe the Rizgary cohort as a population sample.
- Do not invent labels, scan times, outcomes, or performance results.
- Record dataset versions, code commits, seeds, exclusions, and deviations.
- Use the relevant Chapter 2 sections listed in each workspace as the literature starting point, then expand the review independently.

## Workspaces

- `MSC1_Cohort_Characterisation` — retrospective radiology cohort analysis.
- `MSC2_Sequence_Optimisation` — matched MRI sequence-ablation study.
- `MSC3_Radiology_NLP` — level-resolved report information extraction.
- `MSC4_Clinical_Prognostics_PENDING` — conditional imaging–clinical linkage project; not currently allocatable.

The source plans remain in `plan/`. Selar’s PhD methodology remains in `thesis/chapter3.tex`; MSc students should not silently modify it.
