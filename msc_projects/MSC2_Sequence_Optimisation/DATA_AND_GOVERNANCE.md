# Data and Governance Checklist

- [ ] Hospital/ethics approval recorded.
- [ ] DICOM copy de-identified and audited before student access.
- [ ] Private tags and burned-in text reviewed.
- [ ] Scanner and sequence metadata handling approved.
- [ ] Patient-level folds created and locked.
- [ ] Report-to-image and level correspondence verified.
- [ ] Actual sequence acquisition durations obtained from approved sources.
- [ ] Local labels restricted to defensibly supported findings.
- [ ] Raw DICOM preserved read-only.
