# MSc 2 — Sequence-Sparing MRI Protocol Evaluation

## Purpose

Evaluate whether selected lumbar MRI sequence sets preserve diagnostic performance for defensibly labelled findings while reducing measured acquisition time.

This is a local triage/protocol study, not a claim to replace comprehensive diagnostic MRI.

## Start here

1. Read `RESEARCH_PLAN.md`.
2. Complete `DATA_AND_GOVERNANCE.md`.
3. Obtain actual local sequence timing information.
4. Train matched models separately for each configuration.
5. Register all runs in `EXPERIMENT_REGISTRY.csv`.
